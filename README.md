# Revo-coffee-page

Одностраничный промо-лендинг кофейного бренда Revo.
Свёрстан на чистом HTML, CSS и JavaScript без сборщиков и фреймворков.

## Стек

- HTML5
- CSS3
- Vanilla JavaScript
- Swiper.js
- Адаптивная вёрстка

## Возможности

- Полноэкранная шапка с фоновым видео и кнопкой воспроизведения
- Секция преимуществ из четырёх блоков
- Слайдер кофе на Swiper.js с сеткой 2x2 и автопрокруткой
- Слайдер комбо-наборов с адаптивным количеством слайдов
- Блок Giftset с переключением карточек по вкладкам
- Кастомные кнопки навигации для обоих слайдеров
- Адаптивность от широких мониторов до мобильных экранов

## Запуск

Проект не требует сборки и зависимостей.

1. Клонировать репозиторий:

```

git clone [https://github.com/exskyy/Revo-coffee-page.git](https://github.com/exskyy/Revo-coffee-page.git)

```

2. Перейти в папку проекта:

```

cd Revo-coffee-page

```

3. Открыть index.html в браузере.

## Секции страницы

- Header — логотип, заголовок, фоновое видео, корзина и вертикальное меню
- Info — четыре блока с преимуществами бренда
- Coffee-slider — карусель сортов кофе с ценами и кнопками
- Giftset — карточки подарочных наборов с переключением по вкладкам
- Combo — карусель комбо-наборов со скидками
- Footer — копирайт

## Адаптивность

- Desktop: от 1200px
- Laptop: 1024px — 1200px
- Tablet: 768px — 1024px
- Mobile: 480px — 768px
- Small mobile: до 480px

На экранах менее 480px видео скрывается, а сетка шапки перестраивается в две колонки.
